# Protótipo de Tela (Wireframe Textual)

## 1. Tela de Login (login.html)
```text
[☀️/🌙] (Toggle Theme no canto superior direito)
+---------------------------------------+
|               🔐 Acesso Restrito      |
+---------------------------------------+
|  [ Usuário (e-mail)             ]     |
|  [ Senha                        ]     |
|  [ 🏠 Home / ⚖️ Datajud (select) ]     |
|                                       |
|  [         Entrar             ]       |
|                                       |
|  (Mensagem de erro, se houver)       |
+---------------------------------------+
```

```text
[☀️/🌙] (Toggle Theme no canto superior direito)

+---------------------------------------+
|   Você está logado com sucesso.       |
|                                       |
|  [          🚪 Sair           ]       |
```
